# Atividades de JavaScript

Esta pasta reúne as atividades práticas desenvolvidas durante as aulas de JavaScript.

## Estrutura das aulas

### [Aula 01](./Aula_01)

Introdução ao JavaScript, incluindo material de estudo e uma lista de exercícios.

- `Lista_Exercicios_1` — Lista de exercícios da aula.
- `Material_Estudante_JavaScript_Aula01_CEUB.md` — Material didático em Markdown.
- `Material_Estudante_JavaScript_Aula01_CEUB.pdf` — Material didático em PDF.

### [Aula 02](./Aula_02)

Atividades sobre estruturas condicionais e exercícios práticos em JavaScript.

- `exercicio-01-par-impar.js` — Verificação de número par ou ímpar.
- `exercicio-02-desconto.js` — Cálculo de desconto.
- `exercicio-03-acesso.js` — Verificação de acesso.
- `Lista_exercicios_2` — Lista de exercícios da aula.
- `Aula_02_Todos_Exercicios` — Exercícios reunidos em uma pasta.
- `laboratorio-idade` — Laboratório relacionado à idade.
- `laboratorio-media` — Laboratório relacionado ao cálculo de média.

### [Aula 03](./Aula_03)

Atividades relacionadas ao cálculo de média.

- `Calculadora de Média.md` — Documento com a proposta da atividade.
- `Calculadora_media_aula3` — Implementação da calculadora de média.

## Tecnologias utilizadas

- JavaScript
- HTML
- CSS
