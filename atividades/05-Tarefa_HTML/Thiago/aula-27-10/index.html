Essential Git & GitHub Quick Guide

Git is a distributed version control system widely used in software development and web engineering. It allow developers to track source code changes, create project restore points, and collaborate efficiently within programming teams.

GitHub is a cloud-based hosting platform for Git repositories. It provides a web-based graphical interface to manage code, perform code reviews, and showcase open-source projects, making it essential for building a professional developer portfolio in Systems Analysis and Development (ADS).

Core Git Workflow

Follow this standard four-step sequence to prepare and push your local code updates to a remote repository:

  1. git status: Checks the current state of your working directory and staging area (modified, untracked, or staged files).
  2. git add .: Adds all updated and new files to the staging area, preparing them for the next commit.
  3. git commit -m "message": Saves the staged snapshot to the project history with a descriptive comment.
  4. git push origin main: Uploads all local branch commits to the remote GitHub repository.

Command Reference Cheat Sheet

Git Command Description & Purpose
git init Initializes a brand-new Git repository in the current folder.
git clone [url] Downloads a local copy of an existing remote GitHub repository.
git checkout -b [name] Creates and immediately switches to a new development branch.
git pull origin main Fetches and merges the latest changes from the remote repository.
git log Displays the commit history log for the active branch.
