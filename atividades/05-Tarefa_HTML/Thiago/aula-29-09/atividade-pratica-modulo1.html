Guia Rápido: Comandos Essenciais do Git e GitHub

O Git é um sistema de controle de versão distribuído amplamente utilizado no desenvolvimento de software e sistemas web. Ele permite rastrear alterações no código-fonte, criar pontos de restauração no projeto e trabalhar de maneira colaborativa em equipes de programação.

O GitHub é uma plataforma baseada na nuvem que hospeda repositórios Git. Ele oferece uma interface gráfica para gerenciar o código e interagir com outros desenvolvedores, sendo essencial para estruturar um portfólio profissional na área de Análise e Desenvolvimento de Sistemas (ADS).

Passo a Passo do Fluxo de Trabalho (Git Workflow)

Siga a sequência abaixo para preparar e enviar suas alterações de código para o repositório remoto:

  1. git status: Verifica o estado atual dos seus arquivos (modificados, não rastreados ou prontos para commit).
  2. git add .: Adiciona todas as modificações para a área de preparação (staging area).
  3. git commit -m "mensagem": Grava as alterações com um comentário explicativo sobre o que foi feito.
  4. git push origin main: Envia os commits locais para o servidor do GitHub no branch principal.

Resumo de Comandos Úteis

Comando Descrição / Função
git init Inicializa um novo repositório Git na pasta atual do projeto.
git clone [url] Cria uma cópia local de um repositório que já existe no GitHub.
git checkout -b [nome] Cria e alterna para uma nova ramificação (branch) de desenvolvimento.
